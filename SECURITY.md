# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email **hi@aback.group** with:

- what you found and where,
- steps to reproduce it,
- what an attacker could do with it.

We will reply within a few days, keep you updated while we fix it, and credit you if you would like.

Things we especially want to hear about:

- any way to see an expense, payment or activity from a private hisab or a group you are not part of,
- any way to sign in as someone else or take over an account,
- any way to change balances you should not be able to change,
- ways to use Khata to send unwanted email.

## Scope

The deployment at `khata.aback.group` and the code in this repository. Please do not run automated scanners against production, test against real people's accounts, or send email to addresses you do not own. Use a local copy (see the README) for testing.

## Supported versions

Only the latest version on `main`, which is what runs in production.
